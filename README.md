## 🛠️ Autres outils utilisés
- **Microsoft Edge** : pour tester et visualiser le site web.  
- **Visual Studio Code (VS Code)** : éditeur de code principal pour écrire et organiser le projet.  
- **WampServer** : environnement local pour exécuter PHP et gérer la base de données MySQL.  

---

## 📂 Structure du projet
- `index.html` : page d’accueil principale.  
- `style.css` : feuille de style pour la mise en page et le design.  
- `script.js` : logique JavaScript pour les interactions.  
- `config.php` : configuration du serveur et connexion à la base de données.  
- `database.sql` : script SQL pour créer et gérer la base de données.
